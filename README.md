# staqkit

staqkit（Structured Tabular Access and Query Kit）は、ファイルベースの Python 解析パイプラインに、意味的な属性によるデータアクセスとスキーマ契約を導入するためのツールである。

解析データと生成条件の依存関係を明示し、データの意味と来歴を追跡できる状態を目指す。

## コンセプト

- 属性ベースのデータアクセス: 物理ファイルパスに依存せず、意味的な属性でデータを参照する。
- データ依存関係の明示化: 入力データ・処理・パラメータと成果物の関係を宣言し、変更の影響を追跡できるようにする。
- スキーマに基づく契約: データの構造と制約を明示し、管理対象のデータに対して検証される。
- 生成関係の追跡: 宣言された生成条件と成果物の整合性を、追跡可能な範囲で確認できるようにする。

目指す状態と要求は[要求定義](docs/requirements.md)に示す。

## 開発環境

Python と [uv](https://docs.astral.sh/uv/) を使用する。

```bash

uv run pre-commit install
uv run pytest
uv run pyright
```

リンターやフォーマッターなどの設定は `.pre-commit-config.yaml`、`.config/`、`pyproject.toml` を参照のこと。
